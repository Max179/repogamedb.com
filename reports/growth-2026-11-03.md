# Growth — 2026-11-03: deciding when to extract

One new indexable, player-facing guide for the R.E.P.O. site, matching the P1 growth bar set by the supermarket site:
a genuine coverage gap, grounded only in facts the site already publishes, with contextual internal links in both
directions. Nothing was pushed or deployed from here.

## Cluster

**End-of-run decision / extraction timing.** Player queries this page answers:
"when should I extract in R.E.P.O.", "is my haul enough", "should we leave now or carry one more load", "when to stop looting".

## Why this is a real gap

The site already had the pieces but no page that makes the decision:

| Existing page | What it covers | What it does not answer |
| --- | --- | --- |
| entry `choosing-when-to-leave` | extractions are recorded, the level interface works from points of interest, the level defines its valuables; explicitly withholds quota/payout numbers | when, in play, the haul is enough |
| entry `extraction-run` | what an extraction point is and that extractions are counted | how to judge the next load |
| entry `the-truck-and-the-end-of-a-run` | end-of-run screen pages (start / not enough / enough / everyone aboard), the healer, per-player extraction tracking | how to use those signals before committing |
| entry `how-a-run-is-scored` | hauling/scouting/combat/support points, clean-run bonuses, death penalty | the cost of one more risky load |
| entry `the-extraction-point-and-its-machinery` | haul goal, haul bar, surplus steps, focus hints | reading it as a "enough now" signal |
| guide `finishing-a-run-on-your-terms` | how to end the run mechanically (truck, doors, healer) | when to start the ending |
| guide `valuable-run-routine` | how to route loot to the extraction point | when to stop routing |

No existing guide owned the `when to extract` query. The new guide joins those published facts into one decision path
and adds no new numbers, mechanics or claims.
